# 🎵 NovaPlayer

> یک تجربه‌ی موسیقی مدرن، سریع و مینیمال برای ویندوز.

**NovaPlayer** یک پخش‌کننده‌ی موسیقی محلی برای Windows است که با تمرکز روی
سرعت، سادگی، ظاهر مدرن و مدیریت آسان کتابخانه‌ی موسیقی ساخته شده است.

از آهنگ‌های روزمره تا آرشیو بزرگ موسیقی —  
**NOVA همه‌چیز را مرتب، سریع و در دسترس نگه می‌دارد.**

---

## ✨ Features

### 🎧 پخش موسیقی

پخش روان موسیقی با پشتیبانی از فرمت‌های رایج صوتی، از جمله:

- MP3
- FLAC
- WAV
- و فرمت‌های رایج دیگر

---

### 📚 Smart Library

کتابخانه‌ی موسیقی خودت را به شکل مرتب مدیریت کن.

- 🔎 جستجوی سریع
- ↕️ مرتب‌سازی آهنگ‌ها
- 🎵 نمایش اطلاعات آهنگ
- 🖼️ نمایش Artwork
- 📂 مدیریت آسان فایل‌های موسیقی

---

### 🎶 Custom Playlists

پلی‌لیست‌های خودت را بساز و موسیقی را همان‌طور که دوست داری مدیریت کن.

- ایجاد Playlist
- حذف و اضافه کردن آهنگ‌ها
- تغییر ترتیب آهنگ‌ها
- Drag & Drop
- مدیریت آسان مجموعه‌های موسیقی

---

### 🌈 Live Visualizer

موسیقی فقط چیزی نیست که می‌شنوی.

Visualizer زنده‌ی NovaPlayer هنگام پخش موسیقی، یک تجربه‌ی بصری پویا
در اختیار شما قرار می‌دهد.

---
