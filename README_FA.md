# NOVA Player برای ویندوز

این پروژه نسخه دسکتاپ Tauri 2 از فایل اصلی NOVA است. ظاهر، پخش، کتابخانه، پلی‌لیست، LRC، کاور، حالت سینمایی، Drag & Drop، Tray و مینی‌پلیر native داخل پروژه قرار گرفته‌اند. فونت آنلاین حذف شده تا رابط بدون اینترنت هم اجرا شود.

## تازه‌های 1.7.0

- **تب TRENDING 🔥**: چارت ترندهای جهانی خودکار به برنامه اضافه میشه (فید رسمی آیتونز، بدون کلید API). هر آهنگ پیش‌نمایش ۳۰ ثانیه‌ای داره که با همون موتور پخش اصلی پخش میشه؛ آخرین چارت کش میشه و آفلاین هم دیده میشه
- **مینی‌پلیر وینیل 💿**: پنجرهٔ `mini.html` از نو طراحی شد؛ دیسک چرخان، شافل/تکرار با نمایش وضعیت، و خط فعلی متن LRC زیر نام آهنگ. پل وضعیت (`NovaPlayerBridge`) حالا `shuffle`، `repeat` و `lyric` رو هم میده و فرمان `shuffle`/`repeat` رو هم می‌گیره
- **رفع باگ میانبرها**: هندلر میانبرهای سفارشی حالا وقتی فوکوس روی `input`/`textarea`/`contenteditable` باشه اجرا نمیشه؛ دیگه نوشتن «t» تو جستجو تم رو عوض نمی‌کنه
- **راهنمای جدید 📖**: شروع در ۳ قدم، جدول میانبرها، و بخش حل مشکلات رایج

## پیش‌نیازها

1. Node.js نسخه LTS
2. Rustup با toolchain نوع MSVC
3. Visual Studio Build Tools 2022 و گزینه `Desktop development with C++`
4. Microsoft Edge WebView2 Runtime

## اجرای توسعه

در PowerShell و داخل پوشه پروژه:

```powershell
npm install
npm run tauri dev
```

بار اول، دانلود و کامپایل پکیج‌های Rust ممکن است چند دقیقه طول بکشد.

## ساخت فایل نصب

```powershell
npm run tauri build
```

خروجی در این مسیرها ساخته می‌شود:

- `src-tauri\target\release\bundle\nsis`
- `src-tauri\target\release\bundle\msi`

## خبر نسخهٔ جدید (پایدار و بتا)

از نسخهٔ 1.6.0 برنامه خودش Releases گیت‌هاب ریپوی `Mehdi138iimm/NovaPlayer` رو می‌خونه و خبر نسخهٔ جدید رو به کاربر میده، **چه Release معمولی باشه چه Pre-release**:

- بررسی تو Rust انجام میشه (`src-tauri/src/update.rs`، فرمان `check_github_update`) و همهٔ نسخه‌ها، بتا هم، دیده میشن. بالاترین شمارهٔ نسخه (SemVer) برنده‌ست، نه جدیدترین تاریخ
- اگه API گیت‌هاب محدودیت ۶۰ درخواست در ساعت رو زد (رو خط‌های ایرانی زیاد پیش میاد)، از فید `releases.atom` خونده میشه
- ۵ ثانیه بعد از اجرا و بعدش هر ۲ ساعت یه بار چک می‌کنه. اگه شکست خورد، ۲، ۴، ۸، ۱۶ و بعد هر ۳۰ دقیقه دوباره امتحان می‌کنه
- نسخهٔ جدید که بیاد: **دکمهٔ سبز بالا سمت چپ** میاد (با برچسب «بتا» اگه pre-release باشه)، یه اعلان نشون داده میشه و بخش «به‌روزرسانی برنامه» تو تنظیمات دکمهٔ دانلود مستقیم فایل `-setup.exe` رو نشون میده
- کاربر می‌تونه بررسی خودکار رو از تنظیمات خاموش کنه یا با × خبر همون نسخه رو ببنده

**قانون انتشار:** تگ هر Release باید دقیقاً همون نسخهٔ داخل برنامه باشه (مثلاً `v1.6.0`) و هر انتشار شمارهٔ بالاتر بگیره. برای بتا از `v1.7.0-beta.1`، `v1.7.0-beta.2` و ... استفاده کن؛ بتا از نسخهٔ پایدار هم‌شماره پایین‌تر حساب میشه. فایل نصب رو با پسوند `-setup.exe` بذار تا دکمهٔ دانلود مستقیم کار کنه.

## انتشار نسخهٔ جدید

1. شماره نسخه را در هر سه فایل `package.json`، `src-tauri\Cargo.toml` و `src-tauri\tauri.conf.json` یکسان و به شکل SemVer بالا ببر (مثلاً `1.6.1`، یا برای بتا `1.7.0-beta.1`).
2. یا خودت با `npm run tauri build -- --bundles nsis` بساز و فایل `-setup.exe` رو دستی تو یه Release با تگ `v<نسخه>` آپلود کن،
3. یا تغییرات رو push کن و از تب Actions، workflow با نام `Release NOVA Player` رو اجرا کن (تیک pre-release اختیاریه). فایل نصب NSIS ساخته و Release منتشر میشه.

برنامه‌های نصب‌شده (1.6.0 به بعد) چند ساعت بعد خودشون خبرش رو می‌گیرن. نصب خودکار داخل برنامه وجود نداره: کاربر با دکمهٔ «دانلود» فایل نصب رو می‌گیره و اجرا می‌کنه.

## نکات مهم

- بستن پنجره به‌صورت پیش‌فرض برنامه را به Tray می‌فرستد. از منوی Tray گزینه «خروج» را بزن تا کامل بسته شود.
- از آیکون تنظیمات، بخش «محل ذخیرهٔ آهنگ‌ها» را باز کن و هر پوشه‌ای روی هر درایوی که خواستی انتخاب کن. فایل‌های جدید در آن پوشه ذخیره می‌شوند و مسیر انتخاب‌شده برای اجرای بعدی هم حفظ می‌شود.
- برای خطاهای رابط `Ctrl + Shift + I` را بزن.
- آهنگ‌های جدید در پوشهٔ AppData برنامه ذخیره می‌شوند، نه داخل حافظهٔ مرورگر. مسیر انتخابی تنظیمات فقط برای پوشهٔ سفارشی استفاده می‌شود.
- مینی‌پلیر سبک‌تر شده و از داخل خودش کنترل پخش، قبلی، بعدی، Seek و بلندی صدا دارد.
- اگر MSI خطای `light.exe` داد، قابلیت Windows Optional Features > VBSCRIPT را فعال کن یا فقط خروجی NSIS را بساز: `npm run tauri build -- --bundles nsis`.
- در این نسخه فایل صوتی از IndexedDB خارج شده و در فایل واقعی روی دیسک نگه‌داری می‌شود؛ IndexedDB فقط اطلاعات سبک آهنگ را نگه می‌دارد.

## فایل‌های مهم

- `index.html`: رابط و موتور اصلی NOVA
- `mini.html`: مینی‌پلیر native
- `src-tauri/src/lib.rs`: قابلیت‌های ویندوز، Tray، Drag & Drop و کنترل پنجره
- `src-tauri/src/update.rs`: بررسی نسخهٔ جدید از GitHub (پایدار و بتا)
- `docs/index.html`: سایت (GitHub Pages)
- `src-tauri/tauri.conf.json`: تنظیمات پنجره و نصب‌کننده

## بهینه‌سازی مصرف CPU و RAM (نسخهٔ فعلی)

- انیمیشن‌های سنگین (ویژوالایزر، چرخش دیسک، اکولایزر، حلقهٔ صدا) با ۳۰ فریم در ثانیه اجرا می‌شوند؛ از نظر چشم فرقی ندارد ولی نصف کار پردازنده حذف می‌شود.
- وقتی پنجره به Tray می‌رود یا Minimize می‌شود، همهٔ انیمیشن‌ها و ویژوالایزر کامل متوقف می‌شوند و صدا عادی ادامه دارد.
- موتور صدا (AudioContext) هنگام توقف آهنگ به خواب می‌رود و با پخش دوباره بیدار می‌شود.
- فقط آهنگ در حال پخش در RAM نگه داشته می‌شود؛ قبلاً هر آهنگی که پخش می‌شد در حافظه می‌ماند.
- خواندن و ذخیرهٔ فایل صوتی بین Rust و رابط کاربری به‌صورت باینری انجام می‌شود (نه آرایهٔ JSON ده‌برابر حجیم‌تر) و خارج از رشتهٔ اصلی UI.
- مینی‌پلیر فقط وقتی بازش کنی ساخته می‌شود و با بستن کامل از حافظه آزاد می‌شود.
- پروفایل release با LTO و strip کامپایل می‌شود تا فایل اجرایی سبک‌تر و سریع‌تر باشد.
